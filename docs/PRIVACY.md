# الخصوصية

Super Driver مصمم ليعالج بيانات الرحلات محليًا على الجهاز.

- لا يرسل لقطات الشاشة إلى خادم تابع للتطبيق.
- لا يستخدم API خاصة بـUber.
- لا يقبل أو يرفض الرحلات تلقائيًا.
- بيانات الإعدادات تحفظ محليًا عبر DataStore.

استخدام MediaProjection يعني أن Android يمنح التطبيق القدرة على قراءة الشاشة التي يختار المستخدم مشاركتها. يجب تشغيل المراقبة فقط عندما يكون ذلك مقصودًا.
