# Super Driver 🇪🇬

مساعد Android للسائق يقرأ عرض الرحلة من الشاشة، يحلل الأجرة والمسافة والزمن محليًا، ثم يعرض توصية واضحة: **قبول / مراجعة / رفض**.

## ما الذي يفعله؟

- التقاط الشاشة بإذن MediaProjection.
- OCR محلي باستخدام ML Kit للنصوص المدعومة.
- تطبيع الأرقام العربية وعلامات الكسور وصيغ الجنيه المصري.
- تحليل بيانات الاستلام والرحلة.
- حساب **جنيه/كم** و**جنيه/ساعة** والتكلفة والربح التقديري.
- نافذة عائمة فوق التطبيقات لعرض القرار.
- إعدادات محلية محفوظة عبر DataStore.
- لا يقبل أو يرفض الرحلات تلقائيًا.

> **مهم:** طبقة OCR الحالية تستخدم ML Kit للنص اللاتيني. ML Kit Text Recognition لا يوفر حاليًا نموذج OCR عربي أصلي، لذلك دعم النص العربي موجود في التطبيع والتحليل، بينما التعرف الفعلي على النص العربي يحتاج محرك OCR عربي أو الاعتماد على واجهة Uber باللغة الإنجليزية.

## البناء

المشروع يستخدم:

- Android Gradle Plugin 9.0.1
- Gradle 9.1.0
- JDK 17
- compileSdk / targetSdk 36
- applicationId: `com.superdriver.app`

من Android Studio افتح **مجلد المشروع نفسه** الذي يحتوي على `settings.gradle.kts` و`gradlew`. لا يوجد ZIP داخل ZIP ولا مشروع مخبأ داخل `.github/workflows`، لأننا حاولنا بالفعل هذا النوع من العبث ووجدنا أنه يولد أخطاء لا علاقة لها بالتطبيق.

## الأذونات

التطبيق يحتاج إلى:

- إذن التقاط الشاشة MediaProjection.
- إذن الظهور فوق التطبيقات.
- أذونات خدمات foreground المطلوبة لأنواع MediaProjection وSpecial Use.
- الإشعارات على الإصدارات الحديثة عند تشغيل الخدمات في الواجهة الأمامية.

## الخصوصية

المعالجة الأساسية للنص والحسابات تتم محليًا. التطبيق لا يستخدم API خاصة بـUber ولا ينفذ قبولًا أو رفضًا تلقائيًا.

## الحالة الحالية

هذه نسخة Alpha مخصصة للاختبار الواقعي على Android. يجب اختبار OCR على لقطات فعلية من Uber Driver قبل الاعتماد على القرار أثناء القيادة.
